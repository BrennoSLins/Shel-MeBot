# Shel-MeBot
Bot de gerenciamento de RPG para Discord — C# / .NET / Discord.Net

Desenvolvimento de aplicação interativa para gerenciamento de personagens, habilidades, inventário e recursos de jogadores utilizando C# e Discord.Net. Implementação de Slash Commands, botões, Select Menus, Modals e autocomplete, com persistência de dados em JSON.

Desenvolvimento utilizando C# e .NET
Aplicação de Programação Orientada a Objetos
Implementação de arquitetura baseada em Services e Repositories
Utilização de Dependency Injection
Persistência e serialização de dados utilizando JSON
Uso de LINQ para consulta e manipulação de coleções
Implementação de operações assíncronas utilizando async/await
Integração com a Discord API através do Discord.Net
Desenvolvimento de interfaces interativas utilizando Slash Commands, Buttons, Select Menus e Modals
